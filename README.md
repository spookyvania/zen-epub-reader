# Zen EPUB Reader

A minimal, terminal-style EPUB reader in a single HTML file. No install, no dependencies, works offline.

**Use it:** https://spookyvania.github.io/zen-epub-reader/

Or download `Zen EPUB Reader.html` and double-click it.

- Open an `.epub` with the button or by dragging it onto the window
- `≡` or `m` opens the menu: contents, text size, light/dark theme, library
- Pages fit the window: `←` `→`, space, mouse wheel, or a click turn the page
- `-` `+` change text size
- Books and reading positions are stored only in your own browser; nothing is uploaded

DRM-protected books are not supported.
